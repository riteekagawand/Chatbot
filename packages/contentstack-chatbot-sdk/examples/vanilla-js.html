Contentstack ChatBot SDK

This is a demo of the universal Contentstack ChatBot SDK working with vanilla JavaScript.

Features:

  • ✅ Universal compatibility - works with any framework
  • ✅ Real-time Contentstack integration
  • ✅ Smart responses based on your content
  • ✅ Customizable themes and positions
  • ✅ TypeScript support

Try asking:

  • "What type of accommodation do you provide?"
  • "How many tours do you have?"
  • "How can I book a tour?"
  • "What's your cancellation policy?"

Code Example:

import { ContentstackChatBot } from 'contentstack-chatbot-sdk'; const chatbot = ContentstackChatBot.create({ contentstack: { apiKey: 'your-api-key', deliveryToken: 'your-delivery-token', environment: 'development' }, title: 'Travel Assistant', placeholder: 'Ask me about tours and travel...' }); chatbot.mount(document.body);
